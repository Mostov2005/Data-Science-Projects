# Собственная реализация дерева решений для классификации цен мобильных телефонов (My Decision Tree Vs Sklearn: Mobile Price)

## 🔗 Ссылки
- [Датасет на Kaggle](https://www.kaggle.com/datasets/iabhishekofficial/mobile-price-classification)
- [Решение на Kaggle](https://www.kaggle.com/code/mostov/my-decision-tree-vs-sklearn-mobile-price-classific)

## Датасет

Набор содержит характеристики мобильных телефонов и целевую переменную `price_range`  
(0 — `low cost`, 1 — `medium cost`, 2 — `high cost`, 3 — `very high cost`).

### Признаки включают:
- объём памяти, размеры экрана, наличие 4G/3G  
- характеристики камеры  
- ёмкость аккумулятора  
- другие технические параметры

## Задачи анализа

1. Изучение структуры и содержимого набора данных  
2. Подготовка данных для классификации:
   - обработка и удаление дублирующихся данных  
   - разделение признаков и целевой переменной `price_range`  
   - разделение на обучающую и тестовую выборки  
3. Реализация собственной модели Decision Tree:
   - построение дерева с использованием критерия информативности (Gini)  
   - рекурсивное разбиение признаков  
   - предсказание класса по листовым узлам  
4. Обучение и оценка модели `DecisionTreeClassifier` из `sklearn` для сравнения  
5. Оценка качества предсказаний
6. Подбор гиперпараметров дерева (глубина, минимальное количество объектов в узле)  
7. Сравнение работы собственной реализации дерева и библиотеки `sklearn`

## Реализация

В проекте реализовано:
- построение собственного дерева решений для классификации  
- обработка разбиений на основе выбранного критерия (Gini/энтропия)  
- подсчёт метрик качества  
- сравнение с библиотечной моделью (Моя лучше)
