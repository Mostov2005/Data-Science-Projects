# Собственная реализация KNN для классификации цен мобильных телефонов (My_Self_KNN_Mobile_Price)

## 🔗 Ссылки
- [Датасет на Kaggle](https://www.kaggle.com/datasets/iabhishekofficial/mobile-price-classification)
- [Решение на Kaggle](https://www.kaggle.com/code/mostov/my-self-knn-mobile-price)

## Датасет

Набор содержит характеристики мобильных телефонов и целевую переменную `price_range`  
(0 — `low cost`, 1 — `medium cost`, 2 — `high cost`, 3 — `very high cost`).

### Признаки включают:
- объём памяти, размеры экрана, наличие 4G/3G  
- характеристики камеры  
- ёмкость аккумулятора  
- другие технические параметры

## Задачи анализа

1. Изучение структуры и содержимого набора данных  
2. Подготовка данных для классификации:
   - обработка и удаление дублирующихся данных  
   - разделение признаков и целевой переменной `price_range`  
   - нормализация количественных признаков  
   - разделение на обучающую и тестовую выборки  
3. Реализация собственной модели KNN:
   - вычисление расстояний  
   - поиск k ближайших соседей  
   - предсказание класса на основе большинства соседей  
4. Оценка качества предсказаний
5. Подбор оптимального числа соседей `k`  

## Реализация
В проекте реализовано:
- собственный KNN-классификатор с выбором ближайших соседей  
- подсчёт метрик качества
