4. [Business Analyst Jobs](https://www.kaggle.com/datasets/andrewmvd/business-analyst-jobs)  

## Датасет

Amidst the pandemic many people lost their jobs, with this dataset it is possible to hone the job search so that more people in need can find employment.
This dataset was created by picklesueat and contains more than 3900 job listing for data scientist positions, with features such as:

В условиях пандемии многие люди потеряли работу, и с помощью этого набора данных можно усовершенствовать процесс поиска работы, чтобы больше нуждающихся людей могли найти работу.
Этот набор данных был создан picklesueat и содержит более 3900 списков вакансий для специалистов по обработке данных с такими функциями, как:

**Основные поля:**
- `Title` — название вакансии  
- `Company` — компания, предлагающая вакансию  
- `Location` — город и страна  
- `Salary Estimate` — ориентировочная зарплата  
- `Company Rating` — рейтинг компании  
- `Job Description` — описание вакансии  
- `Skills` — требуемые навыки  
- Другие столбцы из оригинальных датасетов  


## Задачи анализа

1. Сбор и объединение данных из четырёх источников: Data Analyst, Data Engineer, Data Scientist и Business Analyst.
2. Анализ представленных данных.
3. Предобработка данных с обоснованием выбранных методов.
4. Кластеризация объединённого датасета на 4 кластера.
5. Визуализация кластеров и сравнение разбиения с исходными наборами данных.
