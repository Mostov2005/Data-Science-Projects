## Датасет

Набор данных содержит информацию о различных образовательных курсах с платформ и организаций, включая:

| №  | Название признака     | Тип данных | Описание                                        |
|----|-----------------------|------------|-------------------------------------------------|
| 1  | index                 | object     | Уникальный идентификатор записи                 |
| 2  | title                 | object     | Название курса                                  |
| 3  | description           | object     | Краткое описание курса                          |
| 4  | difficulty            | object     | Уровень сложности курса                         |
| 5  | certificate_available | bool       | Наличие сертификата по окончании курса          |
| 6  | students              | object     | Количество зарегистрированных студентов         |
| 7  | price                 | float64    | Стоимость курса                                 |
| 8  | rating                | object     | Средний рейтинг курса                           |
| 9  | reviews_count         | object     | Количество отзывов                              |
| 10 | source                | object     | Платформа или организация, предоставляющая курс |
| 11 | course                | object     | Категория или направление курса                 |
