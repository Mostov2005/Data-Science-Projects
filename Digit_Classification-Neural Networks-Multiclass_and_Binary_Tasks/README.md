# Классификация рукописных цифр с помощью нейросетей (NeuralDigits_Classification)

## 🔗 Ссылки
- [Датасет MNIST на OpenML](https://www.openml.org/d/554)
- [Решение на Kaggle](https://www.kaggle.com/code/mostov/digit-classification-neural-networks-multiclass)

## Датасеты

В проекте используются два набора данных с изображениями рукописных цифр:

- `load_digits` — встроенный датасет из `sklearn`, содержащий изображения цифр размером 8×8 пикселей.  
- `mnist_784` — классический датасет MNIST, содержащий изображения 28×28 пикселей, загружается через `fetch_openml`.

Каждое изображение представляет собой цифру от 0 до 9, размеченную соответствующим числовым классом.

## Цели проекта

1. Построение и обучение многоклассовой нейросетевой модели (0–9).
2. Реализация бинарной классификации:
   - чётные против нечётных цифр.
   - ноль (`0`) против остальных цифр.
3. Оценка качества моделей.
4. Визуализация ошибочно классифицированных изображений.
